# AI Tower - Metadata Tagging Technical Application Engine

An agile, production-ready web platform prototype designed to ingest, process, and enrich transcripts using a Natural Language Processing (NLP) runtime architecture. This prototype is configured specifically for direct academic demonstrations and live evaluations.

## 🗼 Core Architecture Infrastructure
- **Frontend Dashboard Framework:** Single Page Application interface crafted in HTML5, leveraging programmatic Tailwind CSS UI nodes alongside native Vanilla JavaScript asynchronous `Fetch API` wrappers.
- **Microservices Engine Backend:** Python Flask-driven application environment serving structural API telemetry endpoints.
- **NLP Analysis Layer:** SpaCy tokenization pipelines running local lexical scanning models to generate explicit Named Entity Recognition tags (`PERSON`, `ORG`, `GPE`, `TIME`, etc.) and frequency-dense metadata indexes.

## 🚀 Execution & Quick Start Guide

### Prerequisites
Ensure your local execution environment has Python 3.8+ installed.

### Step 1: Initialize Your Workspace
Unzip the source tree to a clean folder. Open a terminal prompt directly within the directory root and run:
```bash
# Formulate virtual execution pipeline
python -m venv venv

# Activate standard platform virtual dependencies
# For Windows environments:
venv\\Scripts\\activate
# For Mac/Linux environments:
source venv/bin/activate
```

### Step 2: Provision Dependencies
Install core service modules directly via pip package management utilities:
```bash
pip install -r requirements.txt
```

### Step 3: Run the Application
Boot up the microservice orchestration node:
```bash
python app.py
```
Open a browser client window navigating to the local rendering loop: **`http://127.0.0.1:5000`**

## 💡 How to Demonstrate Live to Your Instructor
1. Launch the page to display the dark-themed **AI Tower** terminal control panel.
2. Click **"Load Sample Use-Case"** above the text area to automatically populate a dense enterprise transcript sample detailing system breaches, locations, and personnel names.
3. Click the bright teal **"⚡ Execute Tagging & Processing"** action node.
4. Point out the instant UI transformation: notice how text parsing metrics populate instantly, alongside an extracted semantic abstract block, interactive color-coded NER tags, and dense metadata keywords.
